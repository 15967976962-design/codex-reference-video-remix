# 宽版柔软发圈：多轮校正案例

这是案例，不是未来所有产品的固定脚本。用户在对话中的解释优先于不准确的自动转录。

| 口播/意图 | 必须看见的画面与结果 | 曾出现的误解 |
| --- | --- | --- |
| “我也是第一次用这么好看的头绳啊” | 从成品里拿出并拉开发圈，有发现新品的惊喜；视觉动作与第一句同步。 | 用普通静态陈列代替动作，或把等待开拍的头部留在开场。 |
| “以前的发圈……” | 当前宽版柔软发圈和小的旧皮筋**同手同框**，让观众一次看懂现在与以前的对比；镜头留够辨认时间。 | 把两个物件拆成两个短镜头，只让旧皮筋闪过，导致约 2–3 秒处跳得太快。 |
| 第一个“要么是这样” | 旧发圈松，模特甩头后位置下滑或发型掉下来；要拍到下滑结果。 | 把手动拆发圈或扎得很好的高马尾当成“松”。 |
| 第二个“要么是一扯一大把头发” | 旧皮筋从头发上被扯/拉出，随后清楚展示带下的一把头发。它与前一个“要么”是两种不同问题。 | 只有拉扯动作或只有一把头发特写，缺少因果；与第一个问题混为一谈。 |
| “新概念名称/柔软材质” | 触摸、捏压和布面近景，表现柔软触感；新概念名称本身也可以形成传播记忆点。 | 把新概念仅当普通产品名称，或在口播开始时放无动作的固定画面。 |
| “纹理、加宽、无接缝” | 使用当前宽版产品的面料近景、展开、触摸或拉伸，让宽度、纹理和连续布面可见。 | 用参考视频中的窄头绳、普通细皮筋或只展示颜色的远景证明当前产品卖点。 |
| 弹力、回弹及扎发效果 | 伸展后回缩；扎发动作完整而自然；之后看见立体、稳固的马尾。 | 整段扎发盲目加速，快到看不懂，或中途跳切掩盖关键步骤。 |
| “关键是一键拆卸不伤发” | 发圈取下，头发散开，取下后的头发或发圈有足够展示时间，观众能判断不伤发。 | 只见拆卸起手或匆匆掠过结果，不能证明“不伤发”。 |
| 结尾发型展示 | 甩头/转头后完整看清扎好的效果，并保留可读的结果帧。 | 在模特转过来、发型刚要出现时就切掉。 |
| “闭眼冲/嘎嘎好用”等行动号召 | 人物手持或主动整理多色宽头绳，表情和手部动作完成推荐；产品保持清楚。 | 结尾只放拆发、空手甩头、完全静止的持物姿势，或在动作开始前结束。 |

## 从多轮成片中固化的规则

- 大小发圈的同框对比曾因旧皮筋只出现约三分之一秒而无法读懂；改为约 0.8 秒的连续关系镜头后才成立。“对比关系”要作为一个视觉单位检索和剪辑，不能按名词拆镜。
- 关键问题动作缺少同等清楚的原素材时，先标记缺口，再决定继续搜索、补拍或按用户授权复用参考片段。多版本可共享不可替代证据，但其他镜头和顺序要变化。
- 固定音轨下，延长一个证据镜头会挤压后续动作。关键问题段要做逐词时间轴，让动作峰值落在关键词附近，不能只按整句大致对齐。
- 原素材常有拍摄口令前等待、动作后的尾巴和重复拍次。先确认有效动作窗口，再算变速。分镜表必须记录第一帧动作和最终证据帧。
- 换一套衣服不等于一条新视频。开场、材质表现、主体动作、结果角度、镜头顺序和收尾都要形成不同观看体验。

## 参考 8–9 新增校正

- 人物连续点头、相似转头或两个托盘依次入画，即使素材文件不同，观感仍然是重复。按“动作功能”去重，不按文件名去重。
- 正脸或横向素材不能直接压成 9:16。先读取旋转信息和像素宽高比，再等比放大并裁切；人物脸型、肩宽和身体比例必须自然。
- 产品入画要保留正确动作阶段。托盘或产品应从画外进入并落到主体位置，不能只留下退出画面或动作结束后的尾巴。
- “想要马尾扎得好”适合直接展示正在甩动、转身或侧转完成的立体高马尾。只保留模特点头而没有最终侧面结果，开场冲击和证据都不足。
- “普通头绳扎上一晃就散”必须看到普通头绳和晃动后的松散结果。素材库缺少同等清楚的替代时，可在用户已授权的范围内复用参考成品的这一小段；两条版本共享一个不可替代证据可以接受。
- “轻松绕三圈”不要求机械保留三次完整重复。可以从后一次绕圈切入，以约 1.6–1.7 倍速完成绕圈、收紧和松手，再把“立体有型”切到同一条素材稍后的成品转侧。
- “一天都不会脱落”应使用真正的甩动、转身或持续佩戴结果；静态背影只能证明已经扎好，不能证明稳固。
- 参考视频是另一款产品时，只迁移语义和结构。正向卖点必须换成当前宽版发圈；参考里的窄产品不能出现在弹力、材质、佩戴效果或推荐镜头中。
- 黑屏加音频的参考没有视觉答案，需要从口播独立建立证据链；不能因为缺少原画面就降低语义匹配标准。
- 轻度磨皮只处理人物皮肤。背部小疙瘩、手部和面部可自然修饰，但发丝边缘、衣物纹理和产品表面纹理必须保留。
- 待审核和已确认是两个状态。所有版本先留在待审核目录；只有用户明确说“保存”后，才把指定版本复制到正式成品库，不能把整批草稿一起归档。
