# 在另一台电脑安装和使用

## 用分享链接安装（推荐）

把 GitHub 中 `reference-video-remix` 文件夹的链接发给同事。同事在 Codex 中只需发送：

```text
请使用 skill-installer 安装这个 Skill：<分享链接>
```

安装完成后，新建任务或进入下一轮消息，使用 `$reference-video-remix` 明确触发。公开仓库无需协作者邀请。Skill 安装器会把文件放到 Codex 的 Skills 目录，不需要同事手动寻找路径。

## 用压缩包安装（备用）

1. 解压分享包，确认最外层文件夹名为 `reference-video-remix`，里面直接包含 `SKILL.md`、`agents` 和 `references`。
2. 将整个文件夹复制到 Codex 的 Skills 目录：设置了 `CODEX_HOME` 时使用 `%CODEX_HOME%\skills\reference-video-remix`；否则通常是 `%USERPROFILE%\.codex\skills\reference-video-remix`。
3. 重启 Codex或开启新任务，让它重新读取 Skills。
4. 在任务中写 `$reference-video-remix`。

## 每次任务要提供

- 参考视频或纯音频的本地路径；
- 当前产品名称和不可混入的其他产品；
- 原始素材库路径；如果已有检索索引，也提供索引路径；
- 是否保留参考原声、需要几条、目标平台和画幅；
- 待审核输出位置；正式成品库位置可稍后给；
- 已经确认的特殊规则，例如允许复用哪一段参考素材。

推荐的单条指令：

```text
使用 $reference-video-remix 处理这条参考视频：<路径>。
产品是：<产品名>；原始素材库：<路径>；镜头索引：<路径，可省略>。
保留参考视频原声，制作 <数量> 条 9:16 待审核版本。
先完整理解口播和参考画面，再按语义选镜；剪掉等待和无效尾巴，必要时自然变速。
未经我确认，不要放入正式成品库。
```

如果素材库很大，同事只需要给文件夹路径，不用逐个上传；Skill 会先建立可检索索引，再选择镜头。

## 素材和运行环境不包含在 Skill 中

Skill 只保存判断规则、工作表和质检流程，不包含任何参考视频、原素材、商品资料、账号信息或历史成片。每位同事使用自己的素材，并填写自己电脑上的实际路径。

执行剪辑的电脑还需要可用的视频处理环境，至少能读取和编码 H.264/AAC、抽帧并检查媒体参数。FFmpeg 最常用；语音识别可以使用现有本地模型或其他可用工具。安装 Skill 后先让 Codex检查运行环境；路径不要求与制作这份 Skill 的电脑相同。

## 建议的团队分工

- 一人维护素材索引：场景、服装、动作、动作起点、证据帧、可用结尾。
- 剪辑者保存 EDL 和待审核版本，不移动原素材。
- 审核者只确认具体版本和问题时间点。
- 归档者只复制已确认文件，并记录日期、产品、序号和哈希。

将用户新指出的共性问题先用于下一轮实践。连续在多个参考视频中验证后，再更新 Skill；不要把一次偶然的素材问题写成所有产品的绝对规则。
